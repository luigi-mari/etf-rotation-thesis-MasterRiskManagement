# ETF Rotation Thesis — A Two-Layer Multi-Asset Selection Framework

A systematic multi-asset rotation framework built around a two-layer selection pipeline and a rigorous pre-modeling feature validation protocol, evaluated out-of-sample on 21 liquid ETFs over 2010–2026 (845 weekly rebalancing periods).

📄 **Full thesis document:** [`Tesi_MRM_Pisa_Luigi_Mari.pdf`](Tesi_MRM_Pisa_Luigi_Mari.pdf) (71 pages).

## What this is

The project develops, stress-tests and documents a complete rotation strategy: from raw price/volume data to validated features, portfolio construction, statistical validation against SPY, and ablation of alternative architectures — including machine-learning variants. The central methodological contribution is a **feature diagnostic conducted prior to any architectural decision**: cross-sectional and time-series Spearman Information Coefficient (IC) audits, a pairwise redundancy map, and an alpha-orthogonality test applied to a pool of fifteen candidate signals spanning price, volume, and volatility dynamics.

This diagnostic formally distinguishes features with **cross-sectional** predictive power (useful for ranking assets relative to one another) from features with **time-series** predictive power (useful for timing individual assets against their own history). The distinction has direct architectural consequences rarely made explicit in the quantitative literature — and is shown to hold even for features that are formally collinear, where standalone predictive strength and genuine incremental information diverge.

## Methodology

- **Layer 1 — cross-sectional momentum funnel** (Jegadeesh & Titman, 1993; Moskowitz et al., 2012): Point-of-Control crossovers + 52-week momentum narrow the universe to trend-aligned candidates.
- **Layer 2 — time-series mean-reversion filter**: Kalman-filter deviations and sign-corrected moving-average slopes select final holdings.
- **Portfolio construction**: ScoreWeighted allocation (ablation vs equal-weight, inverse-volatility, risk-parity family). Risk-parity methods (ERC, HRP; Maillard et al., 2010) underperform simpler rules — their tendency to override directional conviction with variance geometry costs more than it saves.
- **ML benchmarks**: walk-forward XGBoost on the expanded feature set, and a LightGBM ensemble trained directly on a pairwise Learning-to-Rank (LambdaRank; Burges et al., 2005) objective. After transaction costs and weight-drift rebalancing friction, no data-driven model matches the deterministic funnel's execution profile — in small-universe weekly settings, an explicit feature-validated structural prior outperforms models that must discover market geometry unaided.
- **Robustness**: Deflated Sharpe Ratio (DSR) and Probability of Backtest Overfitting (PBO) diagnostics (Bailey & López de Prado, 2014), grid-search over the funnel thresholds, PBO/CSCV analysis.

## Results (strategy vs SPY, gross OOS returns)

| Period | Metric | Strategy | SPY |
|---|---|---:|---:|
| **Full sample** (Jan 2010 – May 2026, N=845) | Annual return (geom.) | **15.30%** | 12.18% |
| | Sharpe ratio | **0.993** | 0.790 |
| | Sortino | **1.452** | 1.143 |
| | Max drawdown | **−21.6%** | −32.2% |
| | Calmar (CAGR / max DD) | **0.71** | 0.38 |
| | Max time underwater | **81 wks** | 103 wks |
| **Out-of-sample** (Jan 2022 – May 2026, N=228) | Annual return (geom.) | **23.06%** | 10.61% |
| | Sharpe ratio | **1.380** | 0.683 |
| | Sortino | **2.320** | 1.030 |
| | Max drawdown | **−13.6%** | −23.4% |
| | Calmar (CAGR / max DD) | **1.69** | 0.45 |
| | Max time underwater | **30 wks** | 100 wks |

Out-of-sample annualised alpha of **+13.4%** (t = 2.87, p = 0.004, HAC-robust); full-sample alpha +5.6% (t = 2.46, p = 0.014), beta ≈ 0.77. The alpha/beta split is structurally stable across the pre/post boundary (Δalpha significant at ~95%, Δbeta insignificant).

**Trading realism:** headline figures are gross. With a 5 bps round-trip commission and ≈23% weekly one-way turnover, full-sample net-of-cost Sharpe is ≈ **0.91** — the edge survives realistic trading friction.

## Repository contents

| File | Description |
|---|---|
| `THESIS.ipynb` | Main thesis notebook: data, features, funnel strategy, ablations, ML benchmarks, statistical test suite vs SPY |

## How to run

```bash
pip install jupyter pandas numpy scipy matplotlib seaborn statsmodels \
            xgboost lightgbm shap yfinance openpyxl
jupyter notebook THESIS.ipynb      # then: Kernel → Restart & Run All
```

Data inputs live in `data/`; if a file is missing it is refreshed from yfinance. Figures are written to `figures/`. Weekly-frequency data; full execution takes a few minutes depending on machine.
